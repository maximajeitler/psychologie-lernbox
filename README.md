# Psychologie Lernbox

Lerntools fürs Psychologiestudium (Uni Graz). Statische Website für GitHub Pages.

- `index.html` – Start: Erklärung, Prüfungskalender, Fächer
- `fach.html?f=…` – ein Fach (Lehrveranstaltungen, Termine, Fach-Rangliste)
- `rangliste.html`, `einstellungen.html`
- `site.css`, `site.js`, `account.js` – gemeinsam für alle Seiten
- `faecher/` – die Lerntools

Gebaut aus den Psychologie-Lerntools (Skill `psychologie-lerntool`).
